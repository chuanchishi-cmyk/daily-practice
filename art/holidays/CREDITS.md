# 節日小卡插圖 · 出處與授權

台灣國定假日（2025 年修法後）＋元宵，共 13 張物件插圖（`<拼音>.webp`，176×176 px，供 88×88 顯示的 2 倍圖）。清明沿用節氣卡（`art/jieqi/qingming.webp`）；小年夜併入除夕。

- **來源**：全部出自《清俗紀聞》（1799 年，長崎奉行中川忠英命人訪問清國商人後編成，記錄清代福建、浙江一帶的年節與生活習俗，石崎融思等人繪圖）。早稻田大學圖書館藏本，Wikimedia Commons 上的 PDF，**公有領域**。沒有使用 AI 生成圖，也沒有 CC BY / CC BY-SA 圖。
- **為什麼用這本**：台灣的年節習俗多半源自閩南，這本書正好記錄閩浙習俗，物件（燈籠、粽子、萬年糧、春福、風箏、爆竹…）齊全，而且整組同一套木刻，風格一致。
- **風格**：原圖是黑白木刻線描。處理時把線條轉成暖褐色 `#5a4b3e`、紙底統一成 `#f6f3ee`，跟節氣卡同一底色；但節氣卡是淡彩，這組是線描。
- **處理**：從跨頁掃描裁出單一物件，去掉題字、頁框與裝訂縫，置中補成正方形後輸出 WebP（無損）。中秋用 1920px 大圖裁切，其餘用 1280px。

## 需要使用者確認

| 節日 | 說明 |
|---|---|
| 行憲紀念日 | 書中找不到憲法、印信這類物件，暫用「聯單」（清代官府發給船隻的文書，上有官印和批註），取「白紙黑字的約定」之意。畫面較雜，內容其實是船籍文書，建議再考慮。 |
| 勞動節 | 書中沒有農具、工具圖（卷二～五我只抽樣看了每三頁一頁），暫用「提盒」，取帶飯上工之意，連結偏弱。 |
| 和平紀念日 | 用的是寺院「中座鈴」（手搖鈴，頂端有佛像紋飾），取「鐘聲、和平」之意。 |
| 國慶日／光復節 | 爆竹、大鼓都是「慶祝」的通用意象，跟這兩個日子沒有特定關聯。 |
| 元旦 | 只裁「新禧 賀 某姓某名恭」題字部分；原圖拜帖外框掃描太淡，沒有保留。 |
| 教師節 | 「上大人 孔乙己」是舊時兒童描紅入門字帖，書中「閭學」（私塾）篇所附，配合 9/28 孔子誕辰。 |
