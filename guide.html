日課是什麼？

給準備考試、寫論文、想好好專注的人的每日練習空間。免下載、免註冊、免費，手機和電腦都能用。

  • 今日今天和明天的三件事、隨手記，節氣與今日小卡
  • 工作上班休息時護眼、喝水、起身走走，接電話計時、工作隨手記與提醒，今天的行程與會談
  • 番茄鐘與白噪音專注計時，夏夜蟲鳴、鳥鳴流水、露營烤火、潮汐，鎖定畫面也會響
  • 計畫地圖大計畫切成小步驟；跟著課程一單元一單元「看、做、檢查」
  • 目標衝刺考試、比賽、演出的倒數，分段練習計時、紀錄與複習
  • 靜心與覺察日記計時靜坐與禪師回饋，記錄情緒與每日回顧
  • 我的節奏與作息觀測找出精力高峰與動力來源，睡眠紀錄每兩週校正
  • 隨手記每一頁右下角都能記下想到的事，可設提醒、加到手機行事曆；生活與工作分開，太長的會先收起
  • 月曆與統計看見每天、每週、每月的累積
  • 運動瑜珈序列、健身連續模式、跑步配速、每日步數
  • 雁書託雁捎書：把心事寫成信交給雁子，明天起床後收到回信

加到手機主畫面，變成 App

  1. 用 Safari 打開 日課網址。
  2. 點下方的「分享」按鈕 （方框加向上箭頭）。
  3. 往下滑，選「加入主畫面」，再按右上角「加入」。
  4. 主畫面會出現日課圖示，之後從這裡打開，就像一般 App。

從 LINE 點開的話：先點右下角「⋯」，選「用 Safari 開啟」，再照上面步驟。在 LINE 裡面沒辦法加到主畫面。

  1. 用 Chrome 打開 日課網址。
  2. 點右上角「⋮」。
  3. 選「安裝應用程式」或「加到主畫面」，再按「安裝」。
  4. 主畫面會出現日課圖示，之後從這裡打開就好。

從 LINE 點開的話：先點右上角「⋮」，選「用預設瀏覽器開啟」（Chrome），再照上面步驟。

  1. 用 Chrome 或 Edge 打開 日課網址。
  2. 網址列右側會出現「安裝」小圖示（螢幕加向下箭頭），點它再按「安裝」。
  3. 日課會變成獨立視窗的 App，也會出現在桌面或開始選單。

Mac 的 Safari：上方選單「檔案」→「加入 Dock」。不想安裝的話，直接加入書籤也可以。

三種用法，選一種就好

  • 手機 App：加到主畫面，最推薦。隨手開番茄鐘、記下想到的事，螢幕鎖定也會響鈴。
  • 電腦 App：安裝成獨立視窗，寫論文時放在旁邊。
  • 網頁：直接打開網址就能用，適合先試試看。

資料存在哪裡？

  • 紀錄只存在你自己的裝置，不會上傳，別人看不到。
  • 手機和電腦的資料是分開的。想搬到新裝置，在「設定 → 資料保護」備份，再到新裝置還原。
  • 建議每週備份一次，可以直接存到雲端硬碟或用 LINE 傳給自己。超過 7 天會提醒你。
  • 想讓手機和電腦自動同步：到「設定 → 資料保護與同步」用 Google 帳號登入。資料會存到你自己的 Google 雲端硬碟（隱藏的 App 資料夾），日課沒有伺服器，看不到你的紀錄。Google 為了安全，每次連線約一小時；之後上方的同步標籤會顯示「⟳ 點一下續上同步」，點一下就好，不用重新選帳號。
