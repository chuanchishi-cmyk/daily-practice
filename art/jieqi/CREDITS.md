# 二十四節氣插畫 · 出處與授權

App 今日頁節氣卡用的 24 張植物插畫（`<拼音>.webp`，176×176 px，供 88×88 顯示的 2 倍圖）。

- **來源**：全部取自 Wikimedia Commons 上國立國會圖書館（NDL）數位化的江戶時代設色植物圖譜，**公有領域**。沒有使用 AI 生成圖，也沒有使用 CC BY / CC BY-SA 圖。
  - 23 張：毛利梅園（1798–1851）《梅園草木花譜》（又稱《梅園百花畫譜》），春/夏/秋/冬之部，手繪設色。

- **授權**：Commons 檔案頁的 License 欄皆為「Public domain」（作者卒年逾百年；NDL 公開為著作權保護期滿）。
- **處理**：從跨頁掃描裁出單株植物，去掉題字、印章、頁邊與裝訂縫；紙色以比值正規化統一為 `#f6f3ee`；飽和度降約 25–34%、略提亮；置中補成正方形後輸出 WebP（無損）。

## 植物對應說明（請使用者確認）

| 節氣 | 說明 |
|---|---|
| 驚蟄 油菜花 | 梅園題「菘菜」，是開黃花的蕓薹屬（*Brassica rapa* 類），與油菜同種群、花形相同。 |
| 清明 柳枝 | 梅園沒有畫垂柳。用的是「水楊」（貓柳，*Salix* 柳屬）帶花序的枝條。 |
| 小滿 鳶尾 | 用的是「燕子花」（*Iris laevigata*，鳶尾屬）。 |
| 芒種 麥穗 | 來自《本草圖譜》，是設色木版，線條較硬，與梅園手繪略有不同。 |
| 秋分 楓葉 | 圖上題「雞冠樹」，是雞爪槭（*Acer palmatum*，即一般說的楓葉），畫的是春天的紅嫩葉與翅果。 |
| 冬至 冬青 | 用的是「枸骨」（*Ilex cornuta*，冬青屬的中國冬青）；梅園冬之部有收，畫的是冬季開花的枝。梅園夏之部目錄另有「冬青」一條，但這次沒有找到該頁。 |
| 立春／大寒 梅花 | 兩張不同：立春用「紅梅」（紅花），大寒用「冬梅」（白梅老枝）。 |
