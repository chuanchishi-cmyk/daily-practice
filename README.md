# 日課 Daily Practice

每天一點，日積月累。番茄鐘、月曆、統計、考試衝刺、論文地圖、覺察日記、靜心與自訂頁面，集中在一個網頁。

- 打開網址就能用，不需要註冊；手機可以「加入主畫面」當 App 使用，離線也能開啟。
- 資料只存在你自己的瀏覽器裡，別人看不到。
- 換電腦或清除瀏覽資料，資料會不見。請定期到「設定 → 匯出備份」下載備份檔，在新裝置按「匯入備份」就能接著用。
